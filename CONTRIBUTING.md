# Contributing

## Issues are welcome

Open an issue for a bug, a question, something the emulator gets wrong about the board, or an idea. It helps to include:

- what you ran, what you expected and what happened, with the output;
- `lcd349 version` and `lcd349 doctor`;
- on the board: its revision and your ESP-IDF version.

For a security problem, see [Reporting a problem](docs/security.md#reporting-a-problem).

## Pull requests aren't taken yet

This repository is published from a private working copy, one commit per version, so a pull request here can't be merged. Please open an issue describing the change instead. That may change once the kit's API settles.
